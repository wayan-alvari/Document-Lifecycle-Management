# Clean-Room Declaration

Document Lifecycle Management is an independent portfolio project created from
scratch from the public specification in this repository.

The implementation uses generic document-lifecycle concepts, newly written
English content, synthetic demonstration data, and dependencies obtained from
their official public distributions. It does not contain or derive from any
employer source code, database schema, migration, route, business rule, user
interface, report, screenshot, configuration, secret, branding, document, or
other proprietary asset.

Any resemblance to an organization, system, person, identifier, or document is
coincidental. The fictional demonstration data is intended only to exercise the
portfolio workflow.
